# Brand assets

The supplied, original PNG assets used by the website are:

- `electrony-xyz-logo .png` — Electrony.xyz wordmark used in page headers. The supplied filename contains a space before `.png`; HTML references encode it as `%20`.
- `electrony-e-logo.png` — Electrony E symbol used in page footers.

The website references these supplied assets. Keep their original colors, proportions and background when using them; the supplied PNGs do not have an alpha channel. Text wordmarks remain as fallbacks if an image cannot load.
